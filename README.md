## О проекте

**NOVO** — это современная торговая площадка, созданная для продажи коммерческого транспорта, сельхозтехники, строительного оборудования и складской техники. Проект объединяет удобный интерфейс продавца, систему тарифов и личный кабинет для управления объявлениями. Написан на нативных **HTML5**, **CSS3** и **JavaScript** без использования фреймворков.

### Главная страница

Презентационная страница с описанием преимуществ платформы:

- **Категории техники**: коммерческий транспорт, сельхозтехника, строительная техника, складское оборудование
- **Преимущества**: понятный мессенджер, удобный дизайн, круглосуточная поддержка
- **Тарифы**: Starter (бесплатно), Premium (999₽/мес), Ultimate (1999₽/мес)
- **Индивидуальные условия**: форма связи для продавцов с большим количеством объявлений

### Регистрация и вход

**Страница входа (`enter_seller.html`):**
- Поля: E-mail, пароль
- Ссылка на регистрацию

**Страница регистрации (`page2.html`):**
- **Аккаунт**: E-mail, пароль
- **О компании**: название, страна, город, адрес, телефон, веб-сайт
- **Контактное лицо**: ФИО, мобильный телефон
- Чекбокс с согласием на условия использования
- Валидация всех полей перед отправкой

### Личный кабинет продавца (`page3.html`)

**Меню навигации:**
- Мои объявления
- Управление подпиской
- Сообщения
- Настройки профиля

**Основной экран:**
- Счетчик использованных объявлений (9/10)
- Поиск по объявлениям
- Карточки товаров с фото, характеристиками и ценой
- Кнопки "Редактировать" и "Удалить" (появляются при наведении)
- Кнопка "ЗАГРУЗИТЬ ЕЩЁ"

### Управление подпиской (`page_sub.html`)

- Отображение текущего тарифного плана
- Информация об оплате и дате окончания подписки
- Возможность смены тарифа
- Блок связи с отделом продаж для размещения >50 объявлений

### Настройки профиля (`settigns.html`)

**Аккордеон-меню:**
1. **Настройки аккаунта** — смена E-mail и пароля, кнопка "Забыли пароль?"
2. **Контактная информация** — редактирование данных о компании (название, страна, город, адрес, индекс, телефон, сайт, время работы) и контактного лица (ФИО, телефон)
3. **Описание компании** — WYSIWYG-редактор на базе Quill.js для форматированного описания

## Адаптивность

| Устройство | Ширина экрана |
|------------|---------------|
| Десктоп    | 1280px и выше |
| Ноутбук    | 1024px — 1279px |
| Планшет (гориз.) | 768px — 1023px |
| Планшет (верт.) | 479px — 767px |
| Мобильные   | 320px — 479px |

**Особенности адаптива:**
- Бургер-меню на мобильных устройствах
- Скрытие некоторых элементов на маленьких экранах
- Изменение сетки карточек товаров
- Адаптивные отступы и размеры шрифтов
